# Roster inicial por departamento

Regla: **equipo = lo necesario, ni más**. Altas/bajas: propone el gerente, aprueba el CEO.

| Departamento | Gerente (skill) | Equipo | Skills de rol |
|--------------|-----------------|--------|---------------|
| Catálogo | `gerente-catalogo` | Data Catálogo (1) | `data-catalogo` |
| Pedidos | `gerente-pedidos` | Ops Pedidos (1) | `ops-pedidos` |
| Personalizados | `gerente-personalizados` | Intake Personalizados (1) | `intake-personalizados` |
| Finanzas | `gerente-finanzas` | Analista Cobranza (1) | `analista-cobranza` |
| Web | `gerente-web` | PM, Dev senior, DevOps, QA, Tester | `web-pm`, `web-dev-senior`, `web-devops`, `web-qa`, `web-tester` |
| Sistema interno | `gerente-sistema-interno` | PM, Dev senior, DevOps, QA, Tester | `sistema-pm`, `sistema-dev-senior`, `sistema-devops`, `sistema-qa`, `sistema-tester` |
| Seguridad | `gerente-seguridad` | Security Engineer, Security Reviewer | `security-engineer`, `security-reviewer` |

## Criterios de ampliación

| Depto | Ampliar si… |
|-------|-------------|
| Catálogo | Hay fotos, variantes o sincronización multi-canal |
| Pedidos | Multi-sucursal o integraciones de mensajería |
| Personalizados | Cola alta o ingeniería de tolerancias |
| Finanzas | CFDI, conciliación bancaria o multi-usuario contable |
| Web / Sistema | Carga de trabajo que el roster no cubra (CEO aprueba) |
| Seguridad | Compliance formal o auditorías externas |

Fichas detalladas: [`depts/`](depts/).
