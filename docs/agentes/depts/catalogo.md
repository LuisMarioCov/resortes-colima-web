# Departamento: Catálogo

## Misión

Mantener la verdad de producto multiusos (dos catálogos Excel → maestro), precios/promos públicos, fotos; bloquear automotriz y stock en canales digitales.

## Gerente

**Gerente Catálogo** — skill `gerente-catalogo`

## Roster

| Rol | Skill | Responsabilidad |
|-----|-------|-----------------|
| Data Catálogo | `data-catalogo` | Import Excel (ID/nombre), atributos, fichas técnicas, pipeline fotos; diffs entre catálogos |

## Reglas actuales

- Identificador: ID / nombre (número); sin SKU formal aún
- Precios públicos; **promos en datos pero no visibles** al público por ahora; **no** usar/mostrar stock
- Fotos: subir y editar fondo/colores antes de web
- Automotriz: fuera de datasets públicos

## Escala al CEO cuando

- Se reactive inventario/stock en producto
- Se pida publicar automotriz
- Cambie la fuente Excel o el modelo de precios/promos
