# Departamento: Web

## Misión

Sitio público de Resortes Colima: catálogo multiusos, Fabricado express, personalizados; sin automotriz; SEO local Colima.

## Gerente

**Gerente Web** — skill `gerente-web`

## Roster

| Rol | Skill | Responsabilidad |
|-----|-------|-----------------|
| PM Web | `web-pm` | Alcance, backlog web, aceptación |
| Dev senior Web | `web-dev-senior` | Implementación frontend/backend web |
| DevOps Web | `web-devops` | Deploy, HTTPS, entornos, CI |
| QA Web | `web-qa` | Criterios de calidad, casos, regresiones |
| Tester Web | `web-tester` | Ejecución de pruebas y evidencias |

## Escala al CEO cuando

- Choque de mensaje de marca o inclusión de automotriz
- Dependencia bloqueante del catálogo maestro o sistema interno
- Decisión de stack/hosting/dominio
