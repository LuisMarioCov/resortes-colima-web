# Departamento: Sistema interno

## Misión

Sistema operativo para pedidos, clientes, facturas, cobros, pagos, notas y catálogo maestro.

## Gerente

**Gerente Sistema** — skill `gerente-sistema-interno`

## Roster

| Rol | Skill | Responsabilidad |
|-----|-------|-----------------|
| PM Sistema | `sistema-pm` | Alcance módulos, backlog interno, aceptación |
| Dev senior Sistema | `sistema-dev-senior` | Implementación de módulos y APIs |
| DevOps Sistema | `sistema-devops` | Deploy, backups, entornos, CI |
| QA Sistema | `sistema-qa` | Criterios de calidad, casos, regresiones |
| Tester Sistema | `sistema-tester` | Ejecución de pruebas y evidencias |

## Escala al CEO cuando

- Prioridad entre módulos choque con Pedidos/Finanzas/Catálogo
- Decisión de stack, hosting o proveedor de datos
- Requisitos de roles/permisos que afecten seguridad transversal
