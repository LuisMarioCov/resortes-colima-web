# Departamento: Seguridad

## Misión

Fail-closed en authz; HTTPS; hash de passwords; cookies de sesión protegidas; RLS; secretos fuera del repo; rate limit; cifrado de datos sensibles. Revisa entregas de Web y Sistema interno.

## Gerente

**Gerente Seguridad** — skill `gerente-seguridad`

## Roster

| Rol | Skill | Responsabilidad |
|-----|-------|-----------------|
| Security Engineer | `security-engineer` | Controles, diseño seguro, remediación |
| Security Reviewer | `security-reviewer` | Revisión de cambios; bloquear merge inseguro |

## Escala al CEO cuando

- Se proponga excepción a fail-closed o secretos en repo
- Haya incidente o duda de cumplimiento
- Choque entre velocidad de entrega y control de acceso
